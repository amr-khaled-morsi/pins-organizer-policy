Privacy Policy for Pins Organizer

Last updated: August 16, 2026

Pins Organizer ("the App", "the Script") is a personal-use automation tool that connects to the Pinterest API (v5) on behalf of its authenticated user to organize pins into boards based on user-defined keyword rules.

1. What data we access

When authorized via Pinterest OAuth, the App may access the following data belonging solely to the authenticated user's own Pinterest account:

  • Pin metadata: pin ID, title, description, alt-text, link, and board ID
  • Board metadata: board ID and board name

2. How we use this data

Pin and board data is used exclusively to determine, locally on the user's own machine, which board each pin should belong to, and to move pins or create boards accordingly via the Pinterest API. Processing happens entirely within the user's local execution environment.

3. Data storage and sharing

The App does not transmit, store, sell, or share any Pinterest data with any third party or external server. No pin content, board content, or access tokens are sent anywhere other than directly between the user's local script and Pinterest's own API endpoints. Access tokens are stored only in a local, user-controlled environment file (.env) and are never transmitted elsewhere.

4. Data retention

The App does not persist a copy of pin or board data beyond the runtime of a single script execution, aside from a local log file (organize_pins.log) written to the user's own machine for troubleshooting purposes. The user may delete this log file at any time.

5. User control

The user may revoke the App's access at any time via Pinterest's account settings under "Apps," which immediately invalidates the associated access token.

6. Contact

For questions about this policy, contact the app owner at the email address associated with the Pinterest developer account under which this app is registered.
